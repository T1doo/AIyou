# AIyou · 爱忆

Android 原生、中文优先、本地优先的私人记忆工具。界面采用暖橙分区与噜噜陪伴，
记录、回忆、待办有独立入口。原始设计保留于
[主方案](docs/AIyou_Master_Plan.md) 与 [产品架构](docs/AIyou_Product_Architecture.docx)。

## 已接通的本地产品路径

- 文字、图片及受控 PCM 原音的记录与草稿，原文版本、附件查看、人工纠错和回收站。
- 中文关键词检索、组合筛选、出处回跳与版本校验；可选人工选词辅助，不生成无证据答案。
- 用户明确输入并确认的原音人工转写与片段范围、偏好及普通事实；保留来源和撤回边界。
- 正式待办与独立待确认草稿，明确操作后的提醒计划及真实调度状态；已安排不等于已送达。
- 用户主动的开放导出、独立口令加密备份／恢复入口；明文风险、严格准入和失败状态保留。
- 噜噜专门互动入口及本地动作，支持关闭／减少动效；不读取记录或调用模型。

默认 `LOCAL_ONLY`，实际构建 APK 不声明 `INTERNET`。模型相关协议和候选处理有自动回归，
但本预览没有真实模型效果验收。图片文字的既有来源纠正／检索链保留；当前提取器不可用，
不能对新图生成文字。真实模型和自动语音识别也未启用，不能包装成仅等设备测试。
