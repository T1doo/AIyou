## 身份与实际执行

- `../frozen/`保留实际策展材料、q19执行前公开时区合同修订、两份gold、分歧裁定、
  两路隔离计划、可见材料/身份声明、冻结链和实际生产候选。操作代理未获gold或语料。
- 实际生产 `QuestionKeywordController`、导航门、`LocalOriginalSearchController`、
  `LocalOriginalSearchMatcher.indexed`、真实SQL/AEAD元数据owner；两路独立同内容数据库。
  使用主机SQLite适配器，原件为合成SQL夹具，不冒称设备SQLCipher加密执行。
- 每路21次查询、H确认前零SQL/一次提交，3道歧义均明确取消且零查询。42份READY结果完成
  真实共同SQL发布确认；32个前五来源的resolve提交ACK及导航门内发布回调均true（合成位置接收端，非Activity/Reader界面导航）。
  每路33份当前来源的正文/修订、人物/别名/日期真实仓库快照均核对冻结语料，删除r31未出现。
- 校准、只生成候选、配对执行分别是1个JUnit方法，均0失败/错误/跳过；
  不是“24题质量全绿”。校准先于最终新增诊断字段/来源回执，最终配对使用
  `execution-freeze.json`中的精确执行器源码；生产源码各阶段未变。
- `independent-arithmetic.json`由另一隔离代理只读原始观察、gold、题目及冻结manifest，
  不读主scorer或summary，独立算术一致；它不能证明标签正确或盲操作溯源。
- 首次评分后只修报告呈现：D的助手动作指标改为不适用，另列D输入及日期确认；
  `quality-first.json`、冻结时scorer及说明保留。主指标和所有输入/观察未改变，没有再查库。
