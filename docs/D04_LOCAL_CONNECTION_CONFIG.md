## 现有设施与缺口

| 现有实现 | 已有职责 | 本批次处理 |
| --- | --- | --- |
| Room v12 / SQLCipher / 同一 EncryptedEntryRepository | 19 张本地表，借用事务、关闭与锁定边界 | 复用同一数据库和 owner，不新建数据库或密钥架构 |
| remote_source_access | 单条来源的 generation、完整连接快照、授权 | 保持来源权限；不能拿来保存未配置的全局连接目录 |
| remote_text_jobs / text_annotations | 已授权作业快照与派生结果 | 不用作配置草稿／目录，也不创建作业 |
| ProviderConnection / SecretReference | 必须含有效 secretRef 的可运行连接快照 | 无凭据配置使用独立类型，不伪造 secretRef 或运行授权 |
| SecretResolver / ResolvedSecret | AI 模块的短生命周期秘密解析接口／内存值 | 尚无 API-key vault；本批次不录入或解析真实密钥 |
| AndroidDatabaseKeyProvider | Keystore 包装现有数据库／附件／编辑密钥 | 不是 API-key vault，不扩大用途、不改变 alias 或封装格式 |
| 两种协议、SSE、MockWebServer | 合成数据协议契约 | 复用固定合成测试；UI 不探测、不自动联网 |
| Settings 模型连接“尚未开放” / bindAi=null | 尚无可持久编辑的用户入口 | 增加本机配置入口；发送能力仍未接入 |

## 本批次的独立闭环

按主方案 §5.5、§8.1、§11.1 增加专用配置表及 Room 12→13 加法迁移，不改变原文、
授权、作业或密钥表。一个配置聚合服务连接、手填模型和用途集合，保留独立语义类型；
主方案允许合并物理表。配置持久增改删、冷重开、版本 CAS、相同 mutation 的有限重试、
删除墓碑和页面／owner 退休共同阻止迟到操作回填。未知／损坏数据保留并显示读取失败。
同 ViewModel、同数据库 owner 的配置重建在内存中保留表单及原待确认请求，恢复后先只读
重载并更换页面身份；旧动作失效，待确认请求只能由用户显式重试。明确离页、切换 owner
或示例模式会清理真实编辑会话。组合替换测试不等同实际 Activity 重建或真机验收。

所有配置均“未设置密钥，尚不可调用”，能力 UNKNOWN；没有密钥输入框、连接测试按钮、
模型列表获取、client 构造、授权、作业或网络请求。保存配置不改变 LOCAL_ONLY，不影响
当前草稿和既有记录。仅允许 HTTPS 根路径，保留自定义前缀，拒绝 userinfo、query、fragment。

配置是本机连接设置，不进入本批次资料库备份；设置入口明确说明。加密备份恢复只判断
资料内容是否为空，不覆盖本机连接配置。Room v13 导出及 fixture 只能由真实 KSP 生成；
本机缺已接受许可 SDK 时不合成导出，以自然 CI 生成的原字节为准。

真实 vault／secretRef 生命周期、能力探测、运行授权与目录版本关联、生产 bindAi 接线
属于后续 D04 切片，本次不声称 D04 全部完成；如超出原方案数据库／密钥架构或引入新许可，
