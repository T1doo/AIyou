# 所选出处时间线：原检索的离线降级视图

原计划 §5.2 要求回答附日期、原文片段和跳转，§10.3 要求没有证据时退回原文。本轮只补正式入口中的离线摘录视图，**没有完成这两节的 AI 问答**，也没有用摘录替代计划中的 AI 回答。

## 用户行为

在回忆中查找关键词或精确片段，主动进入本机出处候选、选择并确认后，才出现独立的“所选出处时间线”及生成按钮。确认不会自动生成。每条仅显示选定记录当前版本的精确摘录、记录日期、原 IANA 时区、版本和查看原文入口。按记录时刻升序，同毫秒按源 ID 稳定排序；原检索及已确认选择顺序不变。

这里的日期是记录时间，即使检索使用事件日期筛选，也不能视为事件发生时间。视图仅涵盖当前选择，不能判断是否回答问题、总共发生几次或事实是否成立；候选达到上限时另行提示。原文仍可能含未选中的其余内容，摘要不补写它们。

## 正式回答接口的缺口

`AIyouApp` 原有 `evidenceAnswerFixture: SyntheticEvidenceAnswerProvider? = null` 只接测试端口。正式 Activity 没有提供它，原控制器因此返回 UNAVAILABLE。该端口要求纯内存合成实现，不能通过它接真实 BYOK、网络或文件副作用。已有本机选择确认也不是 ConsentGrant，更不是多源远程发送权限。

本轮通过显式 `localSummary` 接入固定的原文摘录生成器，生产不实现或调用 Synthetic 端口；构造器默认仍关闭，旧合成回答测试合同不变。真实 BYOK 回答的多源发送授权、生产适配器、会话取消、来源约束、结果检查和原生验收仍未接入／未验证，§5.2／§10.3 问答保持未完成。

## 数据与失效边界

复用现有已确认的最多五源、1200 码点／4800 字节摘录包及当前来源 proof。生成在 SQL 事务与控制器锁之外纯内存执行，前后各检查一次来源并等待 COMMIT，最终再核当前会话、选择和请求身份。每段正文等于原引用，元数据单独展示，满额摘录不会因额外标签超限。

账号、锁、路由、问题输入、选择、源版本、删除或 AI_NONE／撤回再恢复改变时，旧结果及迟到生成不能取得当前展示或跳转权限。查看原文仍走既有 `sourceFor`、`canOpen` 和 SQL resolve，不凭显示过的引用直接导航。退出后需要重新选择确认。不保存结果，不加入保存状态，不新增缓存、schema、权限、依赖、凭据、模型调用、事实或任务；LOCAL_ONLY 不变。

## 验证边界

主机测试使用实际控制器和 SQL proof 路径，SQLite 由测试 Python 连接提供；Compose 测试使用正式 AIyouApp 和无 fixture 的入口，但检索端口仍为合成数据。它们均不代表 Android Room／SQLCipher 运行、真机锁定与重启、SAF、无障碍或性能验收。正式 BYOK 真实回答仍未接／未验。
