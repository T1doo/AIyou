# D06 最小统一关键词找回：设计候选

基线：`4f547c09b1b5c6674060a9fff6527768fee11b27`。仅设计，运行代码未改。
遵循两份原方案 §5.2、§8 DerivedText、§10.1–10.4、§12.1–12.2；不修改原方案。
本片不代表完整 D06、语义检索、真实 OCR、ASR 或设备验收。

## 1. 一个可用入口

“回忆”增加“统一关键词找回”，一个输入、主动查找、清空、内容范围和结果页。
范围为“全部／原文／人工转写／图片文字／已采纳普通偏好”，默认全部。
原文高级词法、日期、人物、标签入口保留；本片不重新实现这些筛选。
初始、空白输入或清空只显示输入提示与返回时间线入口，不自动展示全库内容。
明确文案：“逐字查找当前内容，不理解语义”。没有完整结果时不显示“没有找到”。
图片文字只查真实已有派生文字；未安装 OCR 不制造文字、手工替代或假识别结果。
合成引擎结果仍保留现有“非真实 OCR”来源标识。

## 2. 同一查询的确定语义

复用 `PreferenceKeywords.validate`：最多 64 Unicode 码点／128 UTF-16 单元，
拒控制符和不完整代理对。查询不裁切、不折叠大小写、不自动分词或改写。
非空白查询按完整输入逐字匹配：原文当前正文、未撤回人工转写当前文字、
图片派生文字当前版本、已采纳普通偏好的主题或逐字出处。
不查询历史文字、待确认／已拒绝／取代／撤回偏好，也不把偏好文字写进原文。
既有各类型的来源可见规则保持：原文与人工文字不因缺模型而不可用；
图片派生文字／普通偏好仍拒绝 AI_NONE 及过期处理代次，不能套用一个更宽策略。

原文复用 `SqlLocalSearchRepository.candidates` 的中文候选与完整性校验：
现有关键词候选只作召回超集，最后必须对当前正文做完整逐字核验；
单字、标点、短词等继续按既有安全回退。标签／别名召回只能增加候选，
不能在本入口产生“原文命中”。以中文单字／短语、空格、英文大小写、
标点、数字、补充平面字符对照逐字基准，证明不漏合法字面命中。
高亮复用现有原文码点与 `OriginalSearchPreview` 校验；派生内容只在其自身卡片高亮，
不伪造原图字框或原音时间段，不把命中位置套到原文。

## 3. 身份、去重、排序与分页

一个结果组对应精确当前原件 `(entryId, revision, originalHash, generation)`。
同原件的多类命中合为一个组，分别显示证据行和各自查看按钮；不按文字相同去重。
两条原文相同但 ID 不同的记录必须保留；同记录两段同文原音／两张同文图片也必须保留。
证据身份是带类型的稳定 ID：原文版本、转写 ID、图片文字 ID、偏好 ID。
每项另绑定完整版本快照；附件包含完整 `AttachmentIntent`，不只保留文件 ID。
偏好同时绑定内容版本、审阅检查点和行版本；纠正与重新采纳不复用旧点击能力。
出现相同类型 ID 的不一致快照即失败，不“取最后一项”覆盖冲突。

组顺序固定为原件 capturedAtMillis 降序、entryId 升序；组内按类型固定顺序及稳定 ID 升序。
UI key 使用组／证据稳定身份；版本是重新校验依据，不作为跨内容去重依据。
每页最多 20 个原件组，显示前／后页；不得先截各类第一页再合并，遗漏旧页命中。
先取得所选各类完整有界匹配集，再分组排序分页；同一快照翻页不得重复或漏组。
翻页前重新认证保留证明；集合变更则清内容、退役旧页和点击，提示重新查找，
不在旧游标上拼新集合。修改查询或范围立即清结果、游标与消息并推进请求代次。

## 4. 共享加密 owner 的聚合证明

新增借用同一记录 owner 的 `UnifiedKeywordRepository`，不建数据库、索引、schema 或新文件。
`EntryRepository` 可选能力由生产加密仓库及受控 SQL 仓库真实接线；不以 fake gate 替代。
聚合证明是实现私有类型，绑定 owner、原始查询、范围和各类真实证明；不接受调用者 ID 列表。
原文复用真实候选证明及最终逐文核验。其他三类复用各自 live／AEAD／图校验／来源核验，
提取共享内部“完整匹配集 + within 校验”，由原分页方法与聚合方法共同调用。
不得循环七页导致每页重复认证整批媒体，也不得绕过原仓库的完整集合认证。

媒体逐个调用现有 preview 的 AEAD、SHA256、大小与真实格式认证，读完在 finally 清零。
每类每次捕获／重验至多认证其合法集合一次；不借用备份的 64MiB 限制缩小搜索保存域。
保留既有上限：原文最多 10,000 候选扫描／1,000 个认证候选及 Budget 的
1,000,000 UTF-16／4,000,000 UTF-8；每种派生 profile 最多 128 条、每源 20 条、4MiB 密文。
原文上限内完整匹配 + 三种各 128 条，最多 1,384 项证据，分组后只渲染当前页。
不新增全库业务额度，不截断、不跳过损坏条目冒充完整结果。
超界／任一所选类型不可用／密文损坏／来源不一致时清整个所选结果，
给出不含私密内容的失败提示与重试／切换范围动作；其他范围可另发新查询，绝不静默排除。

所有媒体 IO 后，在同一 counted SQL 写事务内最终重验全部保留集合和源：
原文 proof 的 epoch／runtime／当前正文与绑定元数据；各 profile 全集身份、密文摘要、
行版本、审阅／内容版本、匹配成员及分页；每项当前来源修订、hash、generation、
policy、删除／永久删除和精确附件 READY 绑定。包括空集到非空集的变化。
不能只顺序 await 各 repo.resolve 后就当作共同快照；最终 within 校验不得再挂起媒体 IO。
外层一个事务通过才可发布所选全部结果，不提前流出某类成功内容。

事务中的 owner／请求 CAS 使用私有发布票据。UI 不渲染未获事务成功返回的票据；
异常／取消／提交未确认只撤销同票据候选、清结果，不回滚或覆盖更新查询／导航。
点击也先重新认证媒体，再走同一最终联合校验和精确项成员校验，
已确认票据才交给真实原件 reader，reader 再执行现有来源／附件认证。
不把协程取消当作 IO 或 SQL 资源已释放；借用事务仍受原 draining owner 计数管理。
物理文件在认证后被外部非协作篡改的瞬时边界不宣称原子文件锁覆盖，
实际打开原件仍认证并拒绝损坏，绝不返回未认证字节。

## 5. 控制器、生命周期和精确跳转

新增统一控制器与单个原生 Compose 页，复用实际 VM actor 队列、原件 matcher／reader、
原音／原图控制器与偏好出处定位。每次查询、翻页、点击绑定 session/request/navigation。
输入提交前同步推进私有代次并退休旧内容；A→B→A 也不能复活 A 的旧请求。
actor 入队前、开始执行、所有挂起后、最终发布／导航时均核新鲜 owner 与代次。
query、结果、证明、源锚点均仅 RAM，不进 SavedState、Bundle、日志或全备份。
无保存副作用，不触碰原图、原音、原文、偏好或派生文字。

VM 一旦观察来源修订、policy／generation、删除、仓库不可用，立即退役涉及该源的整个
保留快照／请求，包括当前页之外的证明，不能只检查屏幕上的 20 组。
派生文字／审阅操作与统一页互斥；打开修改、恢复、删除等路线前退役统一结果，
新查询经同一 actor 排在已接写入之后；外部变化由最终 SQL 集合复核拒绝。
切导航／设置、后台、关闭、owner 释放立即清内容并隔离迟到结果，不自动续查或播放。
旋转／系统重建不恢复私密证明；丢失证明时按仍存活 focused panel 真实退役，
不是只隐藏旧 reader。确认资源释放前 UNKNOWN 保持真实资源门。

原文点击跳精确版本正文并使用已核码点高亮；偏好点击跳其精确逐字出处；
原音点击传完整认证 anchor 给 openAudio；图片文字点击传完整认证 anchor 给 openImage。
各 reader 渲染必须核 panel.entryId/revision/attachmentId 与当前 route 一致，
旧回调不得令 B 路由显示 A。点击不自动播放、提取、转写或发送。
返回“统一找回”只可复用 RAM 查询／范围，重新查第一页，不恢复旧结果证明。

## 6. 实施与验收门

设计独审后才实施。本候选不运行无变化测试、不推送、不启动 CI。
实现需同步生产源码与 host harness，增加必要真实 SQL／控制器竞争回归和 Compose：

1. 四类同词、同源合组／跨源同文保留、多附件独立身份；稳定排序、跨旧页命中和完整分页。
2. 中文单字／短语及 Unicode 边界对照逐字基准，原文高亮正确；空输入、无结果、不可用非空结果。
3. 保存／纠正／撤回／取代、来源修订／AI_NONE／generation／回收站／永久删除，包含屏外源变化。
4. 派生密文与真实媒体损坏、保留旧证明、认证后末次 SQL 变化、事务提交失败／丢确认，
   所选结果不部分曝光，不能跳原件或报空结果；容量越界不偷偷截断。
5. A→B→A 查询、范围切换、快速切页、取消／后台／dispose、迟到 IO／比较／点击；
   精确票据回滚不伤新请求。真实资源释放与 SQL draining 仍有 ACK 边界。
6. 窄屏／双字号键盘输入、20 组滚动和前后页；原文／音频／图片／偏好精确回跳。
   A 原件→重建保留 VM→旧 panel 退役→B 原件，不得展示／播放 A；返回后重新查找。
7. 既有各仓库相关回归，原方案／Manifest／锁依赖／schema／全备份格式字节保持；
   原全备份恢复仍是数据来源，新增仅 RAM 查询不进入备份。

必要候选测试和独审后正常推原开发分支，再一次既有 40 分钟完整 Android CI。
原条件 lazy-node skip、instrumentation 仅编译、无本地 Android SDK、设备／真实音频／
SQLCipher 设备／真实 OCR NOT RUN 继续单列；不新增权限、SDK、模型、网络、协议或凭据。
