# F05 §5.2 手工人物关联与组合筛选

本切片以独审接受的 `cbaf2618f7d8c2cb6f85d6dd621c001944958ffc` 为基线，分支 `codex/f05-manual-people-20261017`。先核对了本指定环境、唯一写入者、实际 Git HEAD、远端与未提交差异；没有恢复旧实例或假定其他环境文件共享。两份原设计文档完整读取且原字节不变。

原文阅读页提供“关联人物”，用户明确新增或移除称呼；人物筛选由用户输入并应用，精确匹配手工称呼，与关键词、捕获/事件日期、手工标签、收藏、当前版本图片条件取交集，沿用原排序和原文跳转。称呼属于记录，随原文修订保留；它不是历史版本事实、联系人身份或关系推断，同名不表示同一人。没有自动抽取、模型调用或网络服务，默认 `LOCAL_ONLY` 保持，`AI_NONE` 记录仍能手工整理。

人物元数据拥有独立版本和加密域，复用数据库所有者、事务、串行命令队列与既有 AEAD 原语。11→12 只增加 `entry_manual_people`：记录外键、版本、变更 ID、密文。名称不加入原文 FTS，不改原文、草稿、捕获时间、标签或任务。每条记录最多12个称呼，每个40个 Unicode 码点；全局读取最多4096条关联记录，搜索沿用扫描、字符和字节预算。输入、查询、解码数据均不新增明文磁盘缓存或 Android SavedState。

保存按记录当前版本、正文哈希、访问 generation 与人物版本进行 CAS；相同变更 ID 支持不确定提交后的精确重试。成功以读回为准，失败保留输入。账号所有者更换、原文修订、删除/恢复或关闭弹窗后，旧会话不得写入或重开弹窗；已确认且仍属于当前所有者的数据可以刷新筛选。人物变更推进搜索 epoch，使旧匹配、空结果和原文跳转凭据失效。回收站保留加密关联；永久删除清除关联，恢复包回执不能复活已永久删除的副本。

普通 JSONL/Markdown、开放 ZIP 与活动导出包含已声明范围的人物称呼；加密包 v6 将版本化手工名称与既有 v2–v5 元数据一起认证，兼容已有当前/历史原文、图片、事件日期和活动范围。恢复沿用新副本契约：新 ID、本机加密、`AI_NONE`、无远端授权，非空名称建立新的本地版本1，空名称保持无关联版本0；包内源版本仅作来源证明。重放不能覆盖之后的名称修改、清除、回收状态或永久删除。旧包照旧读取，缺少人物能力的所有者拒绝新范围，不能静默丢失名称。

D06 合成问答原型在此停止扩展。实际 Activity 仍没有提供者，普通用户不能生成答案；引用存在不等于语义真实性。这个限制没有通过人物功能更改。
