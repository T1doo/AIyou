# D05 显式标签行到记录标签

本片接续主方案 §5.4、§9.3、§10.2、§10.3：当前已保存原文中的显式标签行 → 本机预览 → 查看来源 → 独立确认 → 加入现有记录标签 → 标签检索／人工移除。它不调用模型，不推断事实或偏好，也不提供持久 TAG 候选批次、拒绝历史或跨进程继续确认。完整 D05 的模型摘要／多标签／结构化记忆和语义支持判断仍 OPEN。

## 规则与用户确认

仅识别行首无缩进的 `标签：#旅行 #生活` 或 `标签:#旅行 #生活`。记号之间使用 ASCII 空格或 tab，支持 LF／CRLF。名称允许 Unicode 字母、数字、组合标记、下划线及连字符，最多40个 code points；不截断、折叠大小写或进行 Unicode 归一化。每行最多12个记号、2048个 UTF-16单元；全部标签行合计最多12个不同名称。相同名称仅保留第一次的原文引用，多行按原顺序合并。任一被识别的标签行不合法时，整个预览显示格式错误，不部分采纳。

普通正文的 `#词语`、问题、行首带引号或缩进的文字不构成此格式。记号存在只证明原文包含它，不证明某事件发生或某偏好成立。界面显示名称及逐字 `#记号`，可跳回原文的半开 code-point 范围；用户另按“确认加入标签”后才写入。取消确认不写库；取消后同项重开、关闭／导航／恢复后的旧确认都无权执行。

已存在的名称不再提供采纳按钮，也不重写原密文。新增只在既有名称末尾追加，完整集合超过12项时整次拒绝。确认后这些是独立的人工记录标签：原文编辑不会自动删除；通过“管理记录标签”使用既有人工编辑器移除，后续旧请求不能重新加回。

## 来源与同一事务

`SqlSourceTagRepository`借用现有 SQL owner、`SqlManualTagRepository.replaceWithin`及其原密文格式；没有新表、Room迁移、密钥或alias。预览是内存快照，绑定source ID/revision/hash、source generation、capture时间／时区、处理政策、规则版本、标签前集合／版本、提议与引用，以及持久的全局`local_search_epoch`。

提交事务重新读取当前来源并重新执行规则，拒绝草稿、旧版本、AI_NONE、回收站及任意阶段的永久删除收据。REMOTE_ALLOWED不会授予网络执行权。`remote_source_access`缺行→插入→删除即使回到generation0，也会推进全局epoch；因此旧内存预览无法借ABA复活。其他记录变化也可能保守地要求重新预览。

首次写要求epoch=E、标签版本=T及前集合完全匹配；一次标签I/U推进epoch到E+1，写入后同事务认证读回并检查。最新回执使用带操作域、长度前缀规范编码的完整请求SHA256摘要作为既有`lastMutationId`，绑定请求身份／时间、来源、政策、规则、epoch、标签前后集合和所选提议。它不是保存完整来源审计的新增表。

精确丢ACK重放只在epoch=E+1、标签版本=T+1、目标集合及完整请求摘要均匹配时返回原密文，不再次写入或合并。任何后续标签编辑、来源／权限变化、无关epoch变化或修改请求元组都冲突。标签CAS、来源验证、epoch和回执同一事务；异常回滚全部数据与索引失效。原有人工标签API、旧cipher及排空生命周期保留。

## 界面及验证边界

详情页“从原文添加标签”是真实入口。预览和确认私有状态不进入SaveableStateRegistry；关闭或重启后重新读取。保存状态未知时隐藏未确认预览／标签反馈，当前会话只保留同一不可变请求用于核对；不会显示假成功或假空列表。关闭预览不会撤回已经提交的标签，用户可在管理标签中移除。

Host测试使用实际规则、SQL事务、现有tag AEAD、独立SQLite连接、ViewModel IO actor及本地索引。Compose测试使用生产路由／controller和受控回执端口，不能替代SQL持久化；native断言编入既有Room／SQLCipher方法，编译／DEX收集不等于设备执行。最终同SHA质量门与实际结果另附收据。
