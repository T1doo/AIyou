## 修复与契约

- 未改筛选直接应用时，保留原来的查询、日期输入对象、历史与查询 epoch，不发起
  多余查询。继续通过现有导航与重入门槛；无变更使用 `acceptsInput`，有变更使用
  `tryChangeInput` 的实际接收结果，关闭的控制器不误报成功。
- 暂存日期／人物改用独立、直接记忆的原生 `TextFieldState`，不进入 SavedState。
  重置替换私密输入 owner；暂存 Undo/Redo 只影响面板，显式应用才改活动查询。
  原有可选只读测试观察器新增日期输入回调，默认无操作，不记录或序列化字段。
- 筛选面板打开时禁用背景筛选按钮。关闭时仍恢复焦点；关键字／日期的真实按键
  派发到实际获得焦点的窗口，而非对弹层误用 Activity 的窗口。
- 旧测试按现有暂存契约验证：无效日期／人物保留在面板报错，不覆盖活动查询；
  清空、源版本失效、旧回调拒收、草稿未改动、原始字符与实际滚动位置断言继续执行。

原有 14 个搜索测试的方法清单未改名／删除。新增正向暂存日期 Backspace、Undo、
Redo 断言及活动查询 epoch 不变检查；清空后的 query/from/through 实际 owner、
Undo/Redo 清除、恢复／销毁后的旧动作拒收检查均保留。

## 最终 APK 的模拟器核对

既有 API 35、Android 15、星夜主题。最终 APK 实际安装并完成：

1. 输入合成查询 `Keyboard`，无修改应用筛选后，查询和准确原文仍在。
2. 实际 `input keycombination` Ctrl+Z／Ctrl+Y 将查询撤销为空、重做为 `Keyboard`。
3. 在面板输入合成日期，实际 Ctrl+Z／Ctrl+Y 将暂存日期撤销为空、重做为原日期。
   取消后活动查询仍为 `Keyboard`，重开面板日期为空。
4. 通过真实控件清空本次合成查询；原文、任务、提醒及设置未修改。

初版设备脚本误把缓存的 IME 视图当作正在显示，多发 Back 退出到桌面。已核实
前台窗口，改为读取当前 `mInputShown`，并在最终 APK 上完整重验；没有将脚本
错误当作产品失败或通过证据。模拟器和本轮 adb 服务均已关闭。
