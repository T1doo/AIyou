# AIyou 功能现状盘点（2026-11-05）

口径：当前开发分支及本轮证据；“有本地路径”不等于整个功能包已验收。
软件仍为开发预览版。**整体产品完成率尚未核定**，不能将代码量、构建成功或
自动测试通过率换算成产品完成百分比。

| 功能 | 当前已有 | 主要未交付／未签收 |
| --- | --- | --- |
| 随手记录 | 文字、图片、受支持原音的导入与播放、草稿、附件路径 | 真实麦克风录音、更多输入格式、中文 IME、中断／进程终止等完整设备矩阵 |
| 原文管理 | 阅读、版本、手工纠正、标签、收藏、人物／别名、回收站 | 新界面所有二级入口的一致性、删除／恢复等设备流程 |
| 本地找回 | 中文关键词、精确片段、日期／标签／人物／媒体／收藏组合、准确原文回跳与版本检查 | 万条中文记录实际性能与质量、完整设备返回／焦点验收 |
| 待办 | 手动创建、标题、日期时区、完成／取消、撤销完成、独立待确认草稿、原文出处 | 各中断／恢复场景；新建输入目前主要在当前会话保留，非完整跨进程草稿交付 |
| 提醒 | 显式确认计划、撤销和调度状态接线 | 不同手机送达、重启／时间／时区／权限变化等场景；安排成功不等于已送达 |
| 数据带走 | 开放导出、独立口令加密备份／恢复入口 | 新装恢复演练仍未成功闭合、真实 SAF、中断、删除传播与容量覆盖核清 |
| 日／周回顾 | 按日期时区组织原始内容与出处的本地路径 | 全设备完整流程与新版二级视觉；它不是 AI 自动摘要 |
| 隐私 | 默认本地处理、权限／授权／应用访问相关代码与接线 | 锁屏／后台遮盖、密钥生命周期、撤权与删除传播等整体验收 |
| 噜噜 | 小型入口、本地动作／反馈、可关闭与减少动效 | 没有启用真实模型陪聊，不能作为已完成的智能陪伴能力 |
| 界面 | 三个原生主入口，三主题自然背景与玻璃基础、可减少动态、部分关键状态已接回实际功能 | 详情、附件、设置、回顾等全页面统一及完整可访问性／性能验收 |
| 真实 AI 能力 | 模型协议、连接、候选、引用与授权相关实现／自动化基础 | 当前预览真实模型、自动语音识别、新图 OCR、真实整理与有出处 AI 问答未启用／未验收 |

当前可核实的比例只有特定测试集：基线 `2e47826…` Linux CI 413 项中 386 项
通过，约 **93.5% 的测试通过率**；这不是产品完成率，也不是最终交付提交的
完整回归结果。本批专项结果与 Windows 全量失败另见 [证据说明](README.md)。

当前工作在保全已有功能、修复原生交互回归并重建整体验收基线。G0 是本轮计划的
基线核查批次，不代表软件只有第一步。完整智能能力、数据／设备风险和全页面
视觉仍有关键工作，不能标成接近正式完工。
