起点为 `f5f9f4bc89c6f2379990bc76b6f4cde1832d72e1`。本批对应 `CORE-01` 的
原生回归恢复，触及 `UX-03`、`UI-03`；这些完整工作包仍为 IN_PROGRESS。
交付提交绑定 `report.json` 的 LF 归一化源码摘要，原方案和归档计划未修改。

## 修复内容

- 新版暂存筛选面板缺少旧版收藏重试入口，部分错误只显示在面板后面的页面。
  已恢复收藏重试和加载禁用状态；人物、标签、事件日期可在相应失败状态下明确
  重试，索引重新整理仍需用户主动操作。标签重试复用现有元数据刷新队列与导航
  输入门槛，没有新建存储通道。错误在前台面板显示，正常状态不增加说明文字。
- 暂存日期和人物不因重试提交或清空；来源不可用时不允许提交相关条件。
  若来源在已应用筛选后变为不可读，结果仍明确失败并隐藏，直到显式重试。
- 查询不为空时保留可操作的关键词／精确片段入口，避免阅读返回后因焦点变化
  把它隐藏。空查询的普通浏览仍保持简洁。
- 原阅读返回逻辑的项清单总包含摘要项，但 Skyglass 折叠状态没有实际摘要项，
  展开后的位置也在搜索项之后。清单现与实际渲染条件和顺序一致；仍严格等待
  视口及项数吻合，没有删除测量门槛、延长等待或改动原位置断言。

原标签、人物、事件日期测试调整为真实的“选条件→应用”，不把选择暂存误当作
立即执行；收藏继续使用独立分类，完整清空与重置暂存筛选分开。原文内容、
版本失效、旧动作、私密 SavedState、时区与实际返回位置的断言保留。
