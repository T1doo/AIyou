## 改动与依据

远端运行 `42014671336` 的实际 MixedCapture XML 是 11 项且全部成功，
workflow 却仍要求 9 项。本批改为校验当前 11 个准确方法名、所属类、
数量、唯一性，以及零失败／错误／跳过；新脚本测试使用真实 workflow
校验片段，拒绝缺项、外来方法、重复、错误类、失败子节点和虚报数量。
当前实际 11 项 XML 也已通过该片段。

原有一次性诊断脚本继续绑定原始来源及准入，不做修改。相关测试将历史
workflow 字节合约移到独立归档，归档逐字节比对 `867f86ed…` 的 Git blob，
保留原 SHA-256；另外检查当前正式 job 的只读权限、依赖、超时和必需检查。
归档不能授权运行任何诊断 job。

原文高亮测试改为先展开真实筛选页中的“更多查找设置”，再执行“清空全部查找，
包括搜索词”。没有把暂存筛选的“重置”当作清空查询，也没有直接修改控制器状态。

图片搜索的 16 个原有方法保持。测试现在通过媒体分类选择图片，日期先暂存再
“应用”；出处候选先经过“更多”，并区分滚出视口与入口收起。搜索控件与弹层
先读取自身语义，未组合的结果再滚动真实列表。来源、撤权、停止、迟到响应和
大字体触区断言保留。

一个旧断言要求清空筛选后整个缩略图控制器为空，但当前普通列表也展示缩略图。
现改为三项归属检查：旧筛选不可再读出任何 tile、当前搜索拥有新身份、
所有剩余 tile 必须归属当前浏览。合法的新列表缩略图继续工作。
