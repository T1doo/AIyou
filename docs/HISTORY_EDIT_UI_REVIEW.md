# 用历史原文继续编辑：D02 局部界面完善

原方案 F02 包含编辑版本，5.4 要求编辑原文新增版本而不能无痕改写证据，D02 包含本机草稿与版本。方案没有明确要求“一键回滚”；本切片完善已保存版本的人工编辑入口，不引入 D08 删除、AI、附件、后台或网络调用。原方案文档保留。

选中历史全文后，“用此版本编辑”仅将完整原文载入内存编辑器，显示来源历史版本及保存基准版本。基准是载入时的当前版本，即 expectedRevision；并发更新后不会把旧基准误称为当前版本。保存复用现有 revise 事务新增版本。历史和当前原文不会被点击入口或取消操作改写。文本与当前原文完全相同时不允许创建无意义新版本。

已有未保存修改时，入口先显示“替换未保存的修改？”；“保留修改”和系统返回保留完整编辑对象与此刻草稿，只有“替换并编辑”创建新编辑会话。确认绑定历史 session/request、所选版本、已知当前版本、待替换编辑 session 和独立确认 ID；取消后重新打开的确认不会接受上次迟到按钮。读取失败、版本变化、关闭重开、离开 composition 的旧回调不能载入旧源或替换编辑。原文和未保存输入不写入 Bundle 或日志。

并发新版本通过现有 expectedRevision 冲突机制拒绝覆盖；保存失败保留历史来源及修改；提交后读失败只能重读，不重复提交事务。此刻草稿与记录编辑始终分开。新增状态无需 schema、依赖或领域接口变更。
