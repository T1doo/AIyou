# 手工标签纵向切片

本片落实两份原方案 F02／F05、§5.2／§10.4 的用户手工标签：原文页明确新增、移除；回忆页以标签与原文字面关键词、捕获日期组合筛选。标签与 AI 候选、正文版本分开，不改原文、草稿、捕获时间或作业。完整 D06／LOCAL_INDEX 仍为 OPEN。

`entry_manual_tags` 使用同一生产 Room／SQLCipher 数据库，v4→v5 只增加空表。标签集合另以 AES-GCM 加密，随机 12 字节 nonce、128 位认证标签；AAD 绑定格式、记录 ID、标签版本和 mutation ID。子密钥用标准单块 HKDF-Expand 从已有随机数据库密钥派生，独立用途，无新 Android alias、凭据、依赖或权限。SQL、加密与解密共享关闭排空入口，排空后再擦除子密钥。

标签保留大小写、内部空白和组合字符，只去除外侧 Unicode 空白。原始输入最多 160 个 UTF-16 单元，规范化后每项 1–40 个码点、最多 12 项；拒绝重复、控制字符、不完整 UTF-16 和纯不可见格式字符。读取失败不会被视为空集合。

标签版本独立 CAS；删除最后标签保留加密空集合并递增版本。最近 mutation 仅在记录仍可用、expectedVersion＋1、规范化标签和 mutation ID 全部吻合时重放成功。后续操作之后，旧请求返回冲突。提交确认丢失使用同一 mutation 重试。只有实际事务及读回吻合后显示成功，失败和冲突保留输入；旧会话／旧版本不能回写新编辑器。

查询、日期、标签条件及编辑输入只留在内存，不进入 Bundle。标签筛选绑定当前不可变标签快照，读取失败、标签版本变化、原文修订或删除会撤销旧结果和旧打开动作。筛选控件使用有界菜单；返回原文列表保留实际滚动位置。

Host 回归使用实际生产 Kotlin SQL／AEAD、真实 SQLite 文件与独立连接，覆盖迁移、回滚、重开、认证、并发 CAS、丢 ACK、空集 ABA、生命周期和实际 VM 接线。它不证明整库 SQLCipher、Android Keystore 或原生执行通过。Compose 使用实际 AIyouApp／Dialog／matcher／controller 与受控 IO 端口，验证 UI 确认、组合筛选、旧动作、窄屏大字与保存状态边界。

v5 Room 导出必须由既有、已许可 CI 工具链真实 KSP 生成。首次缺失时仅生成新导出与 fixture；取回精确字节提交后，最终 CI 在生成前冻结 checkout 字节，再严格核对，禁止静默覆盖漂移。31 个正式原生方法（19 既有＋8 来源绑定＋4 手工标签）与两个重启探针只做 APK／DEX 精确收集；设备原生迁移、生产重启、真机、16 KB 与性能仍 NOT RUN／OPEN。本片继续 LOCAL_ONLY，实际 APK 必须无 INTERNET。
