## 下载与核验

从本仓库 GitHub Release 下载 ZIP 和旁置 `SHA256SUMS.txt`。先校验 ZIP 的 SHA256，
再解压并对照包内 `SHA256SUMS.txt` 校验 APK、安装说明、构建清单和第三方依赖说明。
APK 的独立 SHA256 也列在上方，可与下载页直接比对。Linux 可用 `sha256sum`，
Windows 可用 `Get-FileHash -Algorithm SHA256`；这些操作只读文件，不会安装应用。

## 安装、启动与退出

1. 使用专用 Android 测试设备和合成内容。先确认没有安装包名 `com.t1doo.aiyou` 的现有应用；
   如已有安装，停止本次安装，不卸载、不覆盖、不尝试绕过签名冲突。卸载会删除应用私有数据，
   本预览尚无可签收的新装恢复证据，不应用真实资料试验这条路径。
2. 只有持机人明确选择安装后，使用 Android 自带安装器打开 APK；若需要“允许此来源”，
   由持机人决定，不附带自动授权／ADB 脚本。不要求麦克风、通知、精确闹钟或文件访问批量授权。
3. 从启动器打开 AIyou。主导航为“此刻／回忆／待办”；设置入口保留本地范围及备份恢复说明。
   用一条合成文字检查明确保存反馈，再到回忆查找并打开原文。保存不依赖网络或真实模型。
4. 使用系统返回或 Home 退出。仅在明确决定丢弃本次测试安装与测试数据后，才从系统设置卸载。
   Release 包不含自动清库、自动恢复、模拟器或系统权限修改脚本。

上述是待执行的手动检查步骤，不是本次已经完成的设备测试。
