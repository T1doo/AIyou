## 已有能力与本片缺口

已有 `LocalOriginalSearchMatcher/Controller`、持久词法索引与私有 proof，支持多记录、
当前版本、日期／事件日期、手工标签、收藏、图片及精确片段；已有完整原文定位／返回。
`SourceCitationCard` 已用于设计组件和演示，日／周回顾另有来源卡片。本片不重复实现
检索、排序、索引、日期解释或模型协议，只增加按当前问题／关键词生成的有预算出处视图。

回忆页的“为当前问题选取本机出处候选”复用同一输入与全部筛选。输入仍为字面关键词
（空格分隔、全部包含）或精确片段，不自动理解自然语言问题，不生成总结或模型答案。
用户可随时返回普通原文列表；与图片网格互斥，清空条件同时关闭该视图。

## 预算、引用与权限

- 问题不超过 512 Unicode code points／2048 UTF-8 字节。既有普通查找输入上限未改。
- 候选最多 5 条、每记录最多一条，引用原文正文最多 1200 code points／4800 UTF-8 字节，
  单条沿用最多 240 code points 的现有摘录。按已有命中顺序选取，不重排、不裁出假引文；
  预算内未展示完的候选明确提示，不能冒充全部证据或完整答案。
- 每卡保留 source ID、current revision、原始捕获时间和 IANA 时区、精确摘录及半开
  Unicode code-point 区间。省略号不进入引用。点击来源复用现有 search.open／resolve，
  原文定位使用引用本身的区间；返回沿用列表 key/index/offset，并等待候选视图完成布局。
- 没有匹配文字、仅图片或全部为不参与 AI 的记录时，明确“没有可引用的证据”，不编造
  回答，也不据此断言事情从未发生。查找失败／不合法输入与无证据分开显示。
- AI_NONE 在选取、预算和额外引文处理之前排除；普通人工原文查找保持可用。
  LOCAL_ONLY 和 REMOTE_ALLOWED 的合格记录只作本机候选，不构造或发送模型请求。
- 发布前验证全部 hit 与原私有 proof 的 entry 完整一致，引用逐码点回算原文；使用既有
  counted SQL write lease 复核当前版本、可见性 generation、策略、标签、日期及图片
  范围。图片 proof 内部的有界候选复核仍保留，不为“避免重复检索”删掉安全校验。
- composition／输入／来源实例及单调候选代次控制发布和打开。更改筛选、账号 owner、
  版本、删除或撤权后旧候选不可打开，迟到准备不能恢复。关闭／清空取消工作并清掉
  显示内容；候选、问题和模式不进数据库、日志、DataStore、Bundle 或磁盘缓存。
  裸 `OriginalTextReference` 不是授权令牌，只有当前候选及原来源证明能用于打开。
