## 语义与身份

- 是所属原件的人工标记值，不是联系人、跨记录人物实体或关系推断；同名只作为筛选条件，不保证同一人。
- 仅选择已保存的完整规范名称，延续旧 person 过滤的精确值比较；大小写、组合字符、内部空白继续区分。
- 现有12名称×40码点、12条原件内别名规则不改。别名仍只属于该原件的显式 name 映射；
  不单独作为人物身份、不传递合并，不把别名文本伪造成正文引用。统一关键词仍逐字，原文旧别名候选通道仍是超集。
- 改名沿用移除／新增值，不全局改名。移除再加同名可得相同值ID，但旧集合回执／epoch／请求永不复活。
- 值ID沿用已审标签的库内稳定范围，独立HKDF-Expand info `AIyou/manual-person-selector/key/1`，
  HMAC输入为长度前缀 `AIyou/manual-person-selector/value/1` 与完整规范名；256位小写hex，独立owner私有票据。
  不复用标签ID用途，不把任意UI名字／ID当证明。换库密钥可改变ID；没有schema／备份新字段。
