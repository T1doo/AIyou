保存中或读回未知时明确不作保证。关闭等待最新输入保存，失败恢复可重试/关闭
核对，不把未知 ACK 丢成“已成功”。未完成标题、无效日期输入均可加密冷恢复；
正式确认时才严格校验标题、时间、时区和重复时刻选择，不推断时间。

待办页显示真实“待确认草稿”分组和数量，独立于今天、接下来、已完成等正式待办
计数，可重新读取、打开修改、拒绝。拒绝保留加密决定，不创建任务，也释放活跃
草稿容量。最多 256 条活跃草稿；已拒绝历史与正式任务沿用当前全列表读取规模，
本批没有增加分页或声称大库性能。一个摘录可以通过不同 proposal ID 承载不同
人工意图；双击当前发起动作仍只打开一个会话，不意外创建多份草稿。

保留字面来源的 ID、revision、hash、generation 和 Unicode 范围，不保存摘录副本。

变化、回收或删除后，未确认草稿不能确认，也不能借旧来源写入新版本；列表可
显示用户自己写的标题并标明失效，用户仍可明确拒绝已保存草稿。读取失败/重开/
来源失效时隐藏摘录与确认，不隐藏并丢弃会话输入。私密表单、摘录和确认不进入
Android Bundle。语义候选提取、自动时间推断、系统提醒及模型调用均没有新增。
