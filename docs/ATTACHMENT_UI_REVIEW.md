# 附件查看与返回：有界 UI 修正

基线 b05c446b16e3918237b585bc8dc1fa0743785631。原始 Master Plan 与 DOCX 保留不改。
本切片属于已实现记录/附件页面的质量修正，不代表完整 D02 或后续阶段通过。

## 问题与行为

旧版在列表头插入成功解码的图片，但没有改变尾部点击者的滚动位置；长列表可能看不到结果。
原文正文的局部 ScrollState 也会随附件路由替换阅读页而消失，返回长文时重新从顶部开始。
这是源码与独立 Compose 源码审查确认的可构造问题；本机没有 SDK，旧版实际 UI 复现 NOT RUN。

成功查看现在进入独立有界图片区域，ContentScale.Fit 保留完整画面。应用栏的唯一返回动作与
系统返回先收起图片，再回附件列表；第二次返回回同一当前/历史原文。列表位置由同一附件
session 持有；当前正文按目的地/记录/版本、历史正文按记录/session/所选版本分别持有位置。
只保留滚动数值，不保存图片、来源 URI、明文或文字选择状态。认证、归属与迟到结果守卫沿用原实现。

已有附件在添加区之前。拍摄资料选项及其位置/色彩资料风险保留在选择图片之前；默认选择与
每次 picker 请求冻结规则不变。格式与全部数字限制、版本关联、历史只读限制、元数据说明可从
“图片格式与保存说明”打开并滚动查看。错误与恢复动作继续在列表附近；历史页不提供新增或重试保存。

## 有效验证

新增两个 NATIVE Robolectric/真实 Compose 导航用例：320×640dp、200% 字体、80 行合成当前/历史
原文、24 项 READY 附件。使用生产 controller 与 decoder，仓库为显式合成边界，不冒称 Room/Keystore。
从实际列表尾点击，图片直接显示（测试不滚到图片），确认返回目标至少 48dp、两个实际滚动数值
恢复、同版本正文和两份输入不变、说明可滚动阅读。当前路径调用实际 BackDispatcher；历史路径实际触摸返回。
既有迟到读取、全局失败、历史只读、picker 归属和 JPEG 资料冻结回归继续运行。

替换既有小图片 Preview，不新增渲染数量：380 张总数、60 张附件状态图仍由既有完整守卫核验。

## 边界与设备验收

JVM 合成仓库、原生宿主解码和 Preview 不证明实际相册授权、设备存储、IME、TalkBack 或性能。
无新 SDK 安装/协议、无真实 API、无新增网络权限。实际 CI/截图审阅结果与精确提交另随交付报告，不能以本文件预先声称通过。
17项 native-storage 设备执行与完整 D02 门槛仍 OPEN。JPEG 必要负载界限不证明任意熵流完整性，
输出 bitmap 有界不代表解码过程峰值内存有界。

最小设备验收：沿用已许可 SDK 与获授权设备，当前/历史各一条长原文与24项合成图片；
320dp/200%字体从尾项查看横/竖图，系统返回/应用栏返回，再打开附件；核同一版本与位置、完整画面、
主动作至少48dp、所有限制和隐私说明可读，随后核 PhotoPicker 取消/拒绝、IME、TalkBack和进程恢复。
设备执行必须单独记录真实 APK SHA、设备/API、输入、失败日志及 PASS/FAIL/NOT RUN。
