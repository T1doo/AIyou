# 显式单次多来源授权界面（有限本机演练）

依据原方案 §4.1、§5.2、§8.2、§9.2、§10.3、§14.1。复用已有限接受的持久 authority，未修改两份原始方案、schema、权限、依赖或记录级授权规则。

回忆页先由用户逐项选取与确认原文；该本机确认不创建外发同意。新增独立“核对单次授权演练”入口只在显式注入内存假传输能力时可用。正常启动没有该能力，显示“单次模型发送尚未接入”，默认 LOCAL_ONLY 且无 INTERNET。真实 BYOK、凭据解析和认证 transport 均未接通，无外部模型请求。

审阅面板展示完整问题、问题时刻与 IANA 时区、合成服务、协议、最终操作 URL、模型/配置版本、CONVERSATION 用途，以及每条原文日期、版本、码点范围和精确摘录。既有原文授权与此次摘录/问题的一次使用明确分开；不预选新增来源，不改变原 grant，不保存密钥或内部 secretRef。只读 review 不创建请求组；另一次明确确认消费冻结审阅对象一次，等待持久授权 COMMIT 后才运行内存假传输。

完整协议响应还须经过实际持久 authority 的接受及当前来源 proof、完成回执核验，才能显示待核对结果。无证据明确呈现，不补造答案；引用可用并不证明论断。来源跳转重新核对 proof 和 receipt 后沿用现有原文版本跳转链路。问题、选取、版本/删除、授权代次、会话/锁、服务、owner 或路由变化使旧审阅及结果失效；后台持续复核完成回执，不能把自身 COMMITTED 误当未完成请求失败。

“停止”仅取消本次未完成执行与清理 pending jobs；“撤回本次授权”单独调用现有 withdraw，先隐藏结果，再等待持久确认。撤回确认未知时结果保持隐藏；显式重试复用同一 permit，不重新传输，不修改记录级 grant。真实外发接入后，撤回无法追回已收到的数据/费用；本片没有真实外发。所有问题、选择、确认和答案只在内存，不写 SavedState、事实、任务、长期记忆或新增明文缓存。

验证采用实际 controller/SQL authority/host SQLite 与内存 SSE；Compose 使用实际 root/controller/codec 配合明确合成的 authority port。两者不等同 Android Room/SQLCipher 或设备验收。SDK 新条款与通知权限仍未批准，不接受或配置；设备锁/重启、SAF、原生数据库、可访问性、内存性能与原生仪器执行保持未验。最终测试和同 SHA CI 证据随交付另列。

本地主机定向 **56/56 PASS**：新授权控制器13、既有持久授权14、既有证据回答29；Python **168/168 PASS**。独审两项P2已修复并有回归：活跃读取意外取消必须失效，不能留无人复核的答案；同一请求自然从RUNNING变READY后，已显示的撤回操作仍须作用于该组。前者实际控制RED为1/1失败，修后通过。早期编译错误、完成成员历史的错误测试预期、迟到失效终态断言过窄的失败日志/XML均保全；后者允许权威先拒绝为FAILED或界面先失效为STALE，两者都不得显示回执或旧结果。
