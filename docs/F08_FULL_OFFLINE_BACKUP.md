# F08 完整离线资料库备份

基于原方案 F08／§14.4，以及既有 NEXT-PRODUCT-GAP-PLAN；两份原始方案未修改。
生产入口：回忆 → 加密包 → 完整资料库备份与恢复。旧选定记录包仍单独保留。

## 范围与兼容

v8 是现有加密流的独立逻辑格式，不是 SQLCipher 文件复制。继续使用原有 PBKDF2、AES-GCM、
逐图认证、终止帧与精确 EOF；不会另建数据库或导出设备密钥。v1–v7 的容量与新副本语义不变。
固定表／列来自当前既有 Room 12；本片没有新增 schema、依赖、权限或授权。

| 范围 | 备份和恢复 |
| --- | --- |
| 所有原文、完整修订与各版本原图 | 保留 ID、修订、时间／时区与原文哈希，包括回收站 |
| 收藏、手工标签／人物、事件日期 | 保留版本与 mutation 信息 |
| 正式待办与提案 | 保留身份、状态、日期、来源及拒绝状态；提案仍是提案 |
| 手工事件／情绪记忆、摘录确认 | 保留人工选择、修正历史和失效终态；重新校验来源与版本 |
| 捕获草稿、已保留编辑草稿 | 保留未完成 UTF-16 与图片；不会自动变成正式记录 |
| 完成回执、回收站决定、删除证明 | 保留防重复／丢 ACK 证明；永久删除记录不重建 |
| 联网授权、模型结果／作业、搜索索引 | 排除；索引仅以本机工作重新构建 |
| 提醒 | 保留日期与提醒意图，恢复为无命令的 REVOKED，须重新确认 |
| 密钥、API Key、设备锁、显示偏好 | 排除；完整资料库不等于设备镜像 |

所有支持的数据必须完整。固定上限：256 条记录、4096 个修订、256 张 JPEG/PNG、每张16 MiB、
图片共64 MiB、逻辑清单16 MiB；任务／提案及记忆／确认表各4096行，编辑草稿最多256份。
回执另有固定行数上限。超限不截断。非 READY 附件、捕获中间态、未完成擦除／导入、未知表列／
profile／回执或无法解释的文件会拒绝快照；不会删除它们以便通过检查。

## 一致性、密钥和失败

同一 draining records owner，沿 MEDIA → EDITS → SQL 顺序获取锁。整库清单在单个事务中捕获，
认证全部图片后再核对库存；加密写入前后再次检查完整库存，能检测未选中记录的新增与删除。
每次只处理一张有界原图，不建立明文磁盘缓存。SAF 写后以8 KiB缓冲完整读回比较密文字节数与哈希。

每种单元格继续由原 purpose cipher 认证，外层口令包只承载可移植明文 payload；恢复用新 owner 的
本机密钥重新封装，所有密钥与口令均不进入清单、日志或 SavedState。口令在阶段退出时清空。
来源 REMOTE_ALLOWED 规范化为 LOCAL_ONLY，AI_NONE 保留；source-memory 内部 policy 同步规范化，
源 generation 与人工关系保留。远端 connection／consent 强制 NULL。

首次导入仅允许严格空的逻辑资料库，包括没有旧删除证明。初始化元数据及精确默认空捕获槽可放行；
现有草稿／未保存选择／未知行会拒绝。没有覆盖模式、自动清库或恢复到任意目录的能力。

持久 PENDING 意图先于文件发布，认证文档在导入时重新完整读取。所有行及 DONE 回执在同一最终事务
中提交，提交前再次验空、核对外键和全部逻辑成员。文件已由现有存储在新 key 下认证、同步并发布。
失败保留意图、源文件及 owned ciphertext；同一备份可重试，不能以另一个备份覆盖未知失败现场。
仅现有文件协议能清理该已登记计划的有证明 partial；不会枚举删除未知文件。

DONE 重放只读取稳定完成回执，不重装图片／草稿／记录，不撤销后续编辑或复活后续永久删除。
同一已认证备份 ID 与摘要精确匹配 DONE 后，已恢复的非空草稿不会阻止核对；其他备份仍须通过空目标与当前输入检查。
关闭页面不会否认已开始的提交；同 owner 的实际清单仍刷新，当前新输入和失败图片选择保持原状。

## 验证边界

合成主机测试使用真实 SQLite、平台 JCA、独立 owner/key、加密文件和生产 controller／IO。
真实 Compose 根入口和口令／范围／确认交互由受控 CI 的 JVM 模拟检查。严格使用实际 XML 与同 SHA
CI 回执，子集不重复计数；失败日志保留。

主机 SQLite 不是 Android Room／SQLCipher。真实新装、跨设备、Keystore、SAF 提供器、锁／重启、
无障碍和内存性能尚未完成设备验收；APK 编译及 Preview 均不能代替上述验收。
