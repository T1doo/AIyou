# Companion artwork in this development slice

The app uses the original geometric `NeutralCapybara` Compose drawing as a
neutral, replaceable placeholder. It contains no downloaded reference pixels,
third-party costume, logo, audio or character dialogue model. The uploaded
reference images are not in this repository or APK.

`MascotAssetProvider.Artwork` is the replacement boundary. Business code supplies
presentation state only; the artwork cannot change a record, task, permission or
processing policy. The user can hide the companion and reduce decorative motion.

This is not an approved likeness or a claim of a formal 水豚噜噜 asset licence.
An approved replacement sample and appropriate rights are still required before
using that third-party character's actual assets. No app-store publication or
release is part of this development delivery.
